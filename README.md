Logs analyser v1 (My first project ever):

What it does
    - Counts requests by IP
    - Counts HTTP methods
    - Counts paths
    - Counts HTTP status codes
    - Displays results in formatted table

Instructions:
    1. Put your logs in logs.txt in the following format: IP HTTP_Method Path HTTP_Status_Code
    2. Look at the results
